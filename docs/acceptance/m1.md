## 在有安装权限的 Windows x64 上完成原生验收

1. 打开 Visual Studio Installer，选择 Visual Studio Build Tools 2022 的“使用 C++ 的桌面开发”，包含 MSVC v143 x64/x86 工具和 Windows 10/11 SDK。这一步通常需要管理员权限。
2. 安装 Rust 官方 rustup 并重新打开 PowerShell。在系统 PATH 上使用受支持的 Node LTS 和 npm。缺少 WebView2 的机器安装 Evergreen Runtime。[Tauri Windows 环境](https://v2.tauri.app/start/prerequisites/) · [Rust 安装](https://rustup.rs/) · [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)
3. 在可联网的项目根目录执行下列命令。环境脚本发现缺项时，先补齐所列工具。

```powershell
rustup toolchain install stable-x86_64-pc-windows-msvc --profile minimal --component rustfmt
cargo install tauri-cli --version 2.11.4 --locked
.\scripts\check-windows.ps1
npm ci
npm run build
cargo generate-lockfile --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo tauri build --no-bundle -- --locked
powershell -NoProfile -STA -File .\scripts\smoke-windows.ps1
```

首次解析完成后把 src-tauri/Cargo.lock 提交到功能分支。已有锁文件的后续构建直接运行带 --locked 的命令。CI 在缺少 Cargo.lock 时也能生成并上传该文件，以便取回；只有两个锁文件均纳入 Git、源码树中的锁文件无漂移、原生测试和窗口实测成功，工作流才会通过。开发时可另行运行 npm run tauri -- dev，核对窗口内应用名、连接状态、Idle 和 Cargo 包版本。
