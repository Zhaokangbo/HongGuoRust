- 不涉及 M11-B 缩略图提取、字幕/音轨选择或持久设置；本阶段只做键盘交互。

## 范围

- `空格`/`K`：暂停或继续；`←/→`：后退/前进 5 秒；`J/L`：后退/前进 10 秒；`↑/↓`：音量增减 25%；`M`：静音/恢复上次非零音量；`F`/`F11`：全屏切换；`Esc`：关闭快捷键提示或退出全屏；`?`：显示/隐藏快捷键提示。
- 只使用现有 `set_paused`、`seek_to`、`set_volume`、`set_fullscreen` IPC；真实状态与会话仍由 Rust/libmpv 负责，不在前端假造播放状态。
- 只在播放器有可控活动会话时接收播放键；未知/无效时长禁止快捷 Seek；Seek 限制在 0 与末尾前 0.25 秒之间。
- 内容剧库、输入框、下拉框、链接、按钮、滑块、可编辑文本、文本框焦点均不得触发播放键；Ctrl、Alt、Meta 组合键、IME 组合输入和按键自动重复不拦截。
- 保留旧版 `F11` 与 `Esc` 全屏规则，包括输入框聚焦时。提示窗口开启时屏蔽播放类快捷键，Esc 优先关闭提示。
- 不改 M7/M8 自动连播逻辑、不增加 Provider 自动下一集、不改变 M10-C1/C2 的持久化格式。

## Windows 真机验收（10 项）

- [ ] 1. 本地 MP4 播放中按空格 / K，可暂停和恢复；Paused 状态显示与操作一致。
- [ ] 2. 播放 20 秒 Demo，←/→ 各 Seek 约 5 秒，J/L 各 Seek 约 10 秒；小于零或超出时长时正确截断。
- [ ] 3. ↑/↓ 音量以 25% 阶梯变化，界面下拉与声音同步，0/100 边界不溢出。
- [ ] 4. M 静音，再按 M 恢复上次非零音量；手动选择音量后可正确记住新的恢复音量。
- [ ] 5. F/F11 进入或退出全屏；Esc 退出全屏，原有全屏按钮仍可用。
- [ ] 6. 按 ? 可打开/关闭帮助；帮助期间按播放键不误触发；Esc 优先关闭帮助。
- [ ] 7. 焦点在 URL 输入框、跳转秒数、搜索框、按钮、进度条、下拉框时，空格、字母和方向键优先由该控件处理，不能误暂停/Seek；F11 和 Esc 仍按全屏规则工作。
- [ ] 8. 在剧库搜索/分类/选集时按 K/J/L/M 不影响播放器；Ctrl/Alt/Windows 组合键、中文输入法组合输入不被错误拦截。
- [ ] 9. 无活动会话、加载中、播放报错、Stop 和快速切换剧集时，快捷键不产生越界跳转、旧会话回写、无限重试或 UI 卡住。
- [ ] 10. M7 断点续播/收藏、M8 本地队列/自动连播、M10-B 上下集/EOF、M10-C1/C2 首页和剧集观看历史均无回归。
