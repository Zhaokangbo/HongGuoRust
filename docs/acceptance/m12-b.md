# M12-B — Windows 长时间播放、频繁切集、弱网及资源趋势验收

## 项目基线与边界

M12-B 从 M12-A PR #26 的 SHA 91a4f488a41391a06bb6e6190149b0e00b534f07 派生。该提交的 Windows M1/M2 CI 均全绿，用户明确反馈 Windows **10/10 实机验收全部通过**。

本阶段实现可重复运行的**只读长时间采样和离线趋势分析**。在尚无 Windows 长期采样证据时，不直接声称修好了内存泄漏，也不更改主 libmpv 解码/网络链路、Provider 历史及用户本地数据。

工具只读取选定进程的 PID、启动时间、累计 CPU 时间、当前工作集、Private Bytes、句柄和线程；不读取播放器媒体路径、链接、鉴权数据、命令行参数。不自动调节 Windows 网络、防火墙或代理，不主动停止播放器。**只有显式传入 -CsvPath，才创建一个新 CSV；旧 CSV 不覆盖**。

- scripts/measure-m12b-stress.ps1：Windows PowerShell 只读采样。支持 1～120 分钟、1～30 秒采样间隔，默认 30 分钟每 5 秒。若有多个同名进程必须使用 -TargetPid 指定；同时验证原始进程启动时间，拒绝 PID 重用后的串数据。进程提前退出则报告不完整，返回 exit code 2。
- scripts/m12b-trend.mjs：仅对固定 10 列数值 CSV 进行解析、严格校验与离线统计。
- scripts/analyze-m12b-resources.mjs：Node.js 22.12+/24 CLI，按可选预热窗口剔除启动阶段，用前后 20% 样本中位数、原始增量和线性回归斜率观察资源趋势。仅输出 stdout，可加 --json。
- tests/m12b-trend.test.mjs：测试 PowerShell Export-Csv 的 BOM/CRLF 兼容性、PID/阶段串数据保护、无效数字/NaN、非递增时标、预热统计和稳定资源走势。
- M12-A「运行诊断」仍只读会话、缓冲及 native release 事件，可和 OS 采样报告一起对照。注意播放重启信号不等于 GPU 首帧显示时间。

**解释规则**：单次工作集/私有内存上涨不等于内存泄漏；稳定内存也不证明零泄漏。必须在相同播放负载下重复至少两组数据，并排除首次加载/预热、缓存及外部运行条件影响。**没有预先可信的阈值时，不自动生成通过/失败结论。**

## Windows 本机运行方法

以下示例默认你已启动 HongGuoRust，脚本在本地克隆的 GitHub 仓库根目录。PowerShell 只支持 Windows，Node.js 是项目的既有开发依赖。CSV 文件路径与名字由用户明确指定，建议 D:\Download。若没有这个目录，应先自选实际存在的目录。不要上传包含个人目录名的完整报错截图。

### 第一轮：1 分钟烟测（验证工具链）

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-m12b-stress.ps1 -DurationMinutes 1 -IntervalSeconds 5 -Stage smoke -CsvPath 'D:\Download\m12b-smoke.csv'
    node .\scripts\analyze-m12b-resources.mjs --csv 'D:\Download\m12b-smoke.csv' --warmup-seconds 0

1 分钟烟测需要关闭默认 120 秒预热剔除，否则分析器会因数据不足而拒绝输出，这是预期的严格行为。重复运行时必须用新的 CSV 文件名，以免覆盖已有证据。

如有多个进程，先用下面的命令确认 PID，再在采样命令加入 -TargetPid 和实际数值：

    Get-Process hongguorust | Select-Object Id,ProcessName

### 第二轮：本地 MP4 30 分钟

使用合法的本地 MP4，在同样的画质/分辨率/音轨与窗口大小下运行：

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-m12b-stress.ps1 -DurationMinutes 30 -IntervalSeconds 5 -Stage local_playback -CsvPath 'D:\Download\m12b-local-01.csv'
    node .\scripts\analyze-m12b-resources.mjs --csv 'D:\Download\m12b-local-01.csv' --warmup-seconds 120

再在相同场景下重复一次独立运行，将 CSV 命名为 m12b-local-02.csv。比较 PrivateMiB、WorkingSetMiB、Handles、Threads 各自的 baselineMedian、endMedian、delta 与 linearSlopePerHour；异常时记录是否持续增长及其与操作的时间关系，不把波动直接判定为泄漏。

### 第三轮：人工操作压力

- switching：持续手动切换本地 MP4、合法 Provider 选集、Stop 与再次打开，记录会话/释放指标。
- pause_seek：重复暂停、Seek、音轨/字幕切换和全屏变化，记录是否卡顿与资源变化。
- network_recovery：仅使用拥有播放权限的 HTTPS MP4，在既有安全可控弱网环境中观察 Buffering、断开与恢复；不要调用未知网络攻击/代理工具。如果无法安全复测，明确标记弱网条目「待验证」，不能以本地视频代替。
- close：采样中人工正常退出应用，脚本应停止采集并报告进程提前结束（exit code 2，属于预期场景），同时检查无残留进程。短于目标时长的样本不能冒充完整长运行。

不同工作负载需用不同的 -Stage 与 CSV 文件名。默认不保存任何测量数据，只有显式 -CsvPath 才创建报告。

## Windows 真机验收（10 项）

- [ ] 1. 新版 M12-B 与 M12-A 运行诊断正常启动，不干扰原生 libmpv 和 UI。
- [ ] 2. 默认不带 -CsvPath 时仅打印当前进程资源，不写出报告；采样数据无媒体路径、URL 或日志敏感信息。
- [ ] 3. 1 分钟烟测指定文件可正常保存、分析器可解析；同名报告不会覆盖。
- [ ] 4. 多同名进程时拒绝歧义 PID；-TargetPid 可明确选中目标，进程重启/PID 重用不合并到旧统计。
- [ ] 5. 至少 30 分钟本地 MP4 稳定播放，生成报告并正确计算预热后窗口中位数/增量/斜率。
- [ ] 6. 相同负载再跑至少 30 分钟，比较资源趋势；明显持续增长必须保留待定位结果，不提前宣称不存在泄漏。
- [ ] 7. 人工快速切集/Stop/Seek/变速/音轨字幕的压力场景没有死锁、持续黑屏、跨会话错误操作或残留释放异常。
- [ ] 8. 有权使用的 HTTPS 视频及安全可控弱网环境里，Buffering→恢复和 M12-A 缓冲统计符合实际；若无法安全复测，不得标记为通过。
- [ ] 9. 在采样器运行时人工关闭应用，采样器报告提前退出并停止追踪；无残留 hongguorust.exe，已保存的部分报告不被误认为完整 30 分钟数据。
- [ ] 10. M7/M8 本地库与自动连播、M10 Provider 首页与手动切集、M11 快捷键/预览/字幕/设置、M12-A 运行诊断均无回归；用户数据和已有历史文件原样保留。
