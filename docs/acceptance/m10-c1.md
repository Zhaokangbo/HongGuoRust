# M10-C1 — Provider 剧集观看历史与跨会话续播

## 基线

M10-B PR #19（`311a64c`）已经通过 Windows M1/M2 与 10/10 真机验收。

## 本阶段交付

- `demo` 和 `manifest` Provider 的 HTTPS 选集历史单独保存于 `%LOCALAPPDATA%\\HongGuoRust\\provider-progress.json`，schemaVersion=1；不修改 M7 `library.json`。
- 记录作用域：Provider-scoped series ID + episode ID + 当前媒体目标指纹，包含进度、时长、最近播放时间与完播状态。**不写入 URL、session ID、凭证**。
- 仅已加载并实际启动的活动原生会话写入历史：播放中每隔约 5 秒保存，Seek/暂停/Stop/换集/关闭保存，只有当前 session 的自然 EOF 标记为完播。
- 重启后，未完播且时间点合理的同一媒体源从上次位置恢复；已完播、接近片尾、时长过短或媒体 URL 变化不进行 Seek。
- 作品详情页在现有选集上方展示上次观看集数、时间点及「继续观看」，已完播显示「重看本集」。
- 单集 local Provider 继续使用 M7 数据；M8 本地队列、M10-B 手动切集保留现有规则；无 Provider 自动连播。
- 无权限/缺失媒体不得自动跳集；媒体加载失败不会创建新已观看记录。
- 文件写入采用 pending + flush + write-through 原子替换；损坏文件保留且禁止覆盖，并报告可诊断错误。
