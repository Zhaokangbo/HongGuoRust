# M12-A Windows 验收：运行生命周期诊断与资源基线

## 范围与边界

本阶段从 M11-C2 PR #25 的已通过 Windows M1/M2 + 用户明确验收 12/12 的提交 `816721a89848f275159b6c1a70306c3b3e8af63e` 派生。

**M12-A 仅建立测量机制及可复现基线**：不更改 libmpv 解码算法、URL 加载策略、M7/M10 的持久化历史、Provider 切集或本地自动连播。由 M12-B 再执行较长时间的资源和网络故障测试，以及为 Windows 发布定义指标阈值。

新增 `get_runtime_health` 只读 IPC，由 Rust worker 在原生播放会话生命周期内维护小量内存计数器；不捕获 URL、鉴权信息、媒体文件名、路径或错误详情，不写诊断数据库，进程退出自动清空。前端控制栏按需点击「运行诊断」→「刷新」→「复制诊断」；没有自动轮询。

字段包括：会话打开数、文件加载成功数、libmpv playback-restart 信号次数、自然结束/失败/Stop 次数、缓冲进入次数/累计毫秒/当前未结束毫秒、最近加载耗时、最近第一次 playback-restart 信号耗时、libmpv 释放次数/最近及最大释放耗时。**playback-restart 不是 GPU 首帧实际呈现时间**，CPU/内存/线程/句柄也不是此 IPC 直接测量的内容。

## Windows 进程资源采样脚本

仓库的 `scripts/measure-m12a-process.ps1` 用于从 Windows 进程表按 PID 采样：累计 CPU 时间、工作集 MiB、私有内存 MiB、句柄数、线程数。默认 30 次、每 2 秒一次；如果有多个同名进程，它只取进程 ID 最小的一项，实际运行时应先确认打印的 PID。

在已经启动的 Windows HongGuoRust 上（以仓库根目录为当前工作目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-m12a-process.ps1 -Samples 30 -IntervalSeconds 2
```

脚本默认只在控制台打印、不保存。只有用户显式传入 `-CsvPath 'D:\\Download\\m12a-baseline.csv'` 才会写出 CSV；CSV 只含固定数值及 PID/采样时间，不记录视频信息。资源数值在有/无视频、播放/暂停、窗口显示/隐藏、弱网时可能不同，需对比多组数据，**不能从单次采样推断不存在内存泄漏**。

## Windows 实机验收（10 项）

- [ ] 1. 启动程序后点击「运行诊断」，能够看到会话打开数、缓冲、释放等摘要；「刷新」不会跳转播放/改变音量。
- [ ] 2. 打开一部本地 MP4 后手动刷新：打开数增加、加载成功数增加、最近加载耗时是有限毫秒数；文件名、绝对路径不进入复制的诊断文本。
- [ ] 3. 自然播放至 EOF，再刷新：自然结束次数增加一次；没有循环误计数，主播放器保持正确完播状态。
- [ ] 4. 再打开 MP4 后点击 Stop：手动停止数增加，只有当前会话停止；重复 Stop 不重复计数或误停止新会话。
- [ ] 5. 播放一个无效或无法打开的本地/HTTPS MP4：失败次数增加；复制出的诊断没有媒体 URL、凭证、路径或原生异常详情。
- [ ] 6. 使用经许可的慢速公开 HTTPS MP4/可控弱网环境触发真实缓冲：缓冲次数/累计时间随事件变化，恢复后当前缓冲时间清零，不会因为暂停或重复通知重复累加。
- [ ] 7. 多次切换本地 MP4、Demo/自有 JSON 选集和停止后，libmpv 释放次数增长；最大/最近释放耗时显示合理、没有数值溢出或界面冻结。
- [ ] 8. 打开/刷新/关闭诊断摘要、快速切集与全屏，操作保持流畅、诊断旧会话不会影响新会话；拷贝内容格式易于粘贴进问题反馈。
- [ ] 9. 运行 `measure-m12a-process.ps1`，可以读取 CPU/工作集/私有内存/句柄/线程数。无需提供用户路径；默认不会创建文件。测试后将采样摘要与播放状态一并记录供 M12-B 比较。
- [ ] 10. M7/M8 历史/收藏与自动连播、M10 首页续看/手动选集、M11-A 快捷键、M11-B 缩略图、M11-C1 音轨/字幕、M11-C2 设置持久化及正常退出均无回归。
