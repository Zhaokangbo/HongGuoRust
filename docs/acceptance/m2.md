# M2-A desktop acceptance

The playback probe is opt-in on the feature branch. Build on a Windows x64 MSVC developer machine with WebView2, 7-Zip and the M1 prerequisites. If the system has no Vulkan loader, the preparation script also uses Git and CMake to build the pinned Khronos sources.

```powershell
$native = Join-Path $env:TEMP 'HongGuoRust-mpv'
./scripts/prepare-mpv-msvc.ps1 -Destination $native
$env:LIB = "$native;$env:LIB"
$env:PATH = "$native;$env:PATH"
npm ci
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --features mpv-probe --locked
cargo tauri build --features mpv-probe --no-bundle -- --locked
./src-tauri/target/release/hongguorust.exe
```

The CI executable can also run with the verified libmpv-2.dll in its directory and a system Vulkan loader. Use the branch script `./scripts/get-mpv.ps1 -Destination <directory-containing-exe>` to stage it. Open a known local H.264/AAC MP4 with the button. Check for moving pictures inside the application and audible sound from the selected Windows output. Record the device, display scale, filename and observations. Stop the clip and close the window during a second playback.

| Check | Evidence required |
| --- | --- |
| M1 regression | Unmodified Windows M1 CI job including Idle IPC, window close and process tree |
| Rust and MSVC | Locked feature build and unit tests |
| Presented video | Two generated fixture colors sampled in the video HWND during real playback |
| Audio decode | Decoded output compared with a known 440 Hz AAC tone |
| Audible output | Listener or endpoint recording on a Windows desktop with a playback device |
| M2-B/C | Replacement, shutdown, mixed DPI, minimize/restore, occlusion and 20 cycles after M2-A acceptance |

The fixture is generated on the runner from colors and a sine wave. No third-party media is committed. The probe does not implement the later service contract. The visible-pixel timestamp includes process startup and sampling delay. FileLoaded and PlaybackRestart are not GPU presentation measurements.
