# M10-A — 内容首页、分类发现和现有详情复用

**基线**：M9-B2 已完成 Windows M1/M2 和负责人 Windows 9/9 项实机验收，合入 `main`（`8790ff8`）。

## 本次范围
- 内容剧库默认打开“首页”。首页从真实的 `catalog_search_page` 请求 `all`，
  组合 demo/local/manifest 三个已授权或用户自有来源；绝不使用爬虫、假榜单或伪造评分。
- 首页顶部提供关键词搜索，来源筛选、根据已加载 `genre` 元数据生成的分类芯片；
  展示单个“首页焦点”及其他内容卡片，点击进入**已经存在的**统一详情和选集页面。
- 主页焦点优先展示用户自有清单，其次本地媒体，其次演示条目。
  此规则是**可解释的展示优先级**，不是个性化推荐或热度榜单。
- 初始请求最多 50 条；分页支持加载更多，不重复追加；
  已加载 50 条不是所有来源的完整数据，分类筛选只作用在已加载条目。
- 详情播放继续通过既有 Tauri `catalog_play_episode`。
  `PlayerService`、libmpv 线程、M7 数据库和 M8 播放列表均不修改。
- “浏览完整目录”切换到既有内容探索页面，保留当前来源/搜索词。
- 保留演示内容检索入口、本地视频列表、最近播放、收藏、M9 自有 JSON 导入与清空。
- Node 原生测试覆盖分类去重、分类筛选、焦点优先级和来源标签。
