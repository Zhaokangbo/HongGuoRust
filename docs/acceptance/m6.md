# M6-A Provider foundation — development candidate

Source branch: feat/m6-provider-foundation, based on merged M5 main.

## Scope

- A Rust ContentProvider interface with search, details, episode discovery and
  resolved playable URLs. LocalDemoProvider is the sole initial implementation.
- Three clearly labeled demo catalog entries with stable series/episode IDs.
  Every episode intentionally reuses the single public SampleLib 20-second MP4
  already used in the M3-M5 acceptance tests; this is NOT genuine drama content.
- Tauri IPC catalog_search, catalog_detail, catalog_play_episode. Caller-supplied
  URLs are not accepted by catalog playback; source validation reuses the M3 guard.
- React search, content cards, details, selectable episodes and a return-to-player
  action, without a new streaming stack.
- Rust hides the native STATIC video HWND when catalog is visible and restores
  it when returning to playback. The default 66px header/96px footer native
  viewport is intentionally unchanged, preserving M1-M5 startup and media tests.

## Acceptance requirements (new candidate, not yet verified)

1. GitHub Windows M1 and M2 playback workflows pass on this branch.
2. Rust unit tests cover case-aware discovery, stable IDs, invalid episode and
   series rejection, and bounded search length.
3. On Windows, open the catalog and verify three cards, search "城市", open
   detail, select an episode and confirm actual video playback.
4. Return to catalog then back to player without a black/native window over
   the HTML catalog; check normal closing and full-screen behavior.
5. Confirm invalid IDs do not initiate arbitrary HTTPS playback.
6. No M5 installer or official release is published by this branch.
   M5 redistribution/source compliance continues independently in Issue #7.

## Known limits / next increment

- Content is hard-coded demo data, not a network service, database or licensed
  commercial drama catalog. Do not connect arbitrary scraper/provider URLs.
- No persistence, pagination, playback-history, favorites or real artwork.
- Do not claim native catalog visibility or Windows tests are PASS until run.
