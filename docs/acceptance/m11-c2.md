# M11-C2 — 播放器设置持久化（Windows 实机验收）

## 基线与前置

- 从 M11-C1 PR #24 最新提交 `f1e281c8f53b25d185efb6a0b28896159689b1ad` 派生。M11-C1 Windows 实机用户明确反馈验收通过，PR #24 仍 Draft；早前 #20–#23 也未合并。
- 本阶段的可持久化设置：**音量、上次非静音音量、播放倍速、本地播放列表自动连播开关**。
- 设置文件：`%LOCALAPPDATA%\HongGuoRust\player-settings.json`，独立于 `library.json` / `provider-progress.json` / `owned-manifest.json`。
- 不存储跨媒体音轨 ID、字幕 ID 或外部字幕路径：M11-C1 轨道 ID 仅对当前媒体有效。字幕样式和更丰富的偏好设置另行评估，不纳入此阶段。
- 产品边界：自动连播**仅用于 M8 本地临时播放列表**，M10 Provider 剧集仍要求手动切换下一集。

## 设计与安全性

1. 新增 `src-tauri/src/player/preferences.rs`，schemaVersion=1，最多 16KiB，序列化为无凭证、无 URL、无绝对路径的 JSON。
2. 存储写入使用 `*.json.pending` + `sync_all` + Win32 `MoveFileExW(MOVEFILE_REPLACE_EXISTING|MOVEFILE_WRITE_THROUGH)`。先写磁盘，成功才更新内存；损坏、版本不支持或超大文件时阻止覆盖，要求用户先自行备份检查。
3. Rust 在主 libmpv `Engine::load` 加载文件前，为每次新会话设置保存的 `volume` 和 `speed`，避免重新打开媒体时被 UI 默认值覆盖。
4. 现有 `set_volume` / `set_rate` 经 worker 原生确认后再持久化。磁盘保存失败会尝试回滚原生设置并报告错误，不在 UI 假报保存成功。
5. 新 IPC `get_player_preferences` 和 `set_player_auto_next` 只读写限定字段，不向 WebView 发送真实媒体 URL 或用户路径。
6. UI 不再每次切换 session 就把速率重置 1.0、音量重置 100；初次启动从 Rust 获取偏好并显示。M11-A 的 M 静音、恢复上次非零音量通过同一存储链保存。
7. 仍保留播放/暂停、进度 Seek、Provider 历史、轨道选择、缩略图取帧的既有线程和会话边界。

## Windows 真机验收 12 项

- [ ] 1. 第一次无 `player-settings.json` 时，播放倍速默认 1.0×、音量默认 100%、本地自动连播默认关闭；改动任一设置后创建有效 JSON。
- [ ] 2. 播放本地 MP4 改为 1.5× / 50%，声音/画面速率正确；关闭程序重新打开同一视频，控件与实际声音/速度均恢复。
- [ ] 3. 设定音量 50%，按 M 静音（保存 0）、彻底退出再打开，仍静音；按 M 恢复为 50% 而非错误的 100%。
- [ ] 4. 连续切换两个本地 MP4，再打开 Demo/自有清单 HTTPS MP4：每个新 libmpv session 均继承保存的倍速/音量，不被旧版 UI 重置。
- [ ] 5. 在本地临时列表开启“自动连播”，退出重启重新进入本地播放列表时开关仍选中；自然 EOF 继续下一部，Stop 不推进。
- [ ] 6. 再关闭本地自动连播，重启后仍关闭；本地自然 EOF 不自动切下一部。
- [ ] 7. 即使本地自动连播已开启，Provider 多集作品自然完播时仍只能手动下一集，不能跨 Provider 自动跳。
- [ ] 8. `player-settings.json` 只包含 `schemaVersion`、`volume`、`lastAudibleVolume`、`playbackRate`、`autoNext`；无 MP4 路径、真实 URL 或收藏/进度内容。既有 `library.json` 和 `provider-progress.json` 未损坏。
- [ ] 9. 在**先备份** `player-settings.json` 后临时写入损坏 JSON 或未来 schema，重新启动应显示设置异常，原文件不得被默认值静默覆盖；测试后恢复原始文件。
- [ ] 10. 多次快速音量/倍速修改后关闭再启动，配置文件可解析，状态不是部分写入；无无限循环或新的后台播放器进程。
- [ ] 11. M11-A 键盘快捷键/M 静音、M11-B 悬停缩略图、M11-C1 音轨/字幕切换均正常；轨道 ID 不跨会话保留。
- [ ] 12. M7 收藏/断点续播、M8 原有本地自动连播边界、M10-B 手动上下集、M10-C1/C2 首页续看/剧集历史、正常关闭退出均无回归。
