# M5 Windows NSIS distribution — first implementation

**NOT YET VERIFIED. No public installer release is authorized by this document.**

## Scope

Package the Rust/Tauri app and pinned libmpv-2.dll into a per-user NSIS setup for Windows 10/11 x64. The M5 configuration is an additive override: it preserves existing M1–M4 non-bundle builds.

- src-tauri/tauri.bundle.conf.json enables NSIS only and declares a verified libmpv runtime as bundled resource.
- src-tauri/windows/hooks.nsh copies the runtime from $INSTDIR\resources\libmpv-2.dll beside the installed hongguorust.exe, where Windows can load it.
- scripts/build-windows.ps1 performs npm build, pinned libmpv SHA-256 check, MSVC import-library preparation, Rust tests and NSIS packaging. The staging DLL is removed in finally; never commit the DLL.
- Default current-user installation avoids admin elevation. The default WebView2 bootstrapper requires internet if WebView2 is missing.

Build in Windows PowerShell from repository root:

    .\scripts\build-windows.ps1

Expected candidate: src-tauri/target/release/bundle/nsis/*-setup.exe. **Actual NSIS build and hook behavior still require validation.**

## Acceptance before M5 completion

1. Windows CI/manual build of setup.exe and recorded SHA-256; npm/Cargo lockfiles unchanged.
2. Install on clean Windows 10 and 11 x64 without preinstalled mpv/development tools. Verify libmpv-2.dll is beside executable and matches expected df006bfc754d1212fb2084c6a6da04876882648c025ccb56cf1132b27b1e7913.
3. Test local MP4 and public HTTPS video, pause, seek, volume, fullscreen, stop, exit, upgrade and uninstall.
4. Test WebView2 runtime present and absent, including network bootstrap behavior.
5. Audit native DLL imports (especially vulkan-1.dll), required VC runtimes, and their availability on clean systems. Do not assume a build runner represents a clean machine.
6. BEFORE publishing any setup.exe as a public GitHub artifact or Release, verify actual mpv/FFmpeg/libmpv2/Vulkan licenses, source availability, component notices and compatible redistribution terms. The pinned LGPL build filename alone does not establish compliance.
7. Observe 20 cycles, process shutdown and no unrelated DLL/file removal. Record 100% / 150% DPI behavior.
