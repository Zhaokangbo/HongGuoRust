# M10-B — 作品选集、手动上下集和自然播放结束提示

**已验收基线：** M10-A `96e15b8`，Windows M1/M2 + 11/11 真机场景全部通过。

## 交付范围
- 详情页展示真实 `Episode.number` 升序剧集；后端仍然是 demo/local/manifest 三个已验收 Provider。
- 从详情页打开某一集时，把该**作品完整选集列表**和 Rust `catalog_play_episode` 返回的原生 session ID 作为当前**内存态剧集上下文**。
- 底部播放器展示作品标题 / 当前第几集 / 总集数，以及“上一集”“下一集”按钮。手动切换只允许本作品已有集；首集、尾集和单集本地 MP4 禁用越界操作。
- 只对 **当前原生 session ID 的自然 EOF `Ended`** 显示“本集播放完毕，点击下一集继续”；尾集显示“本作品已播放到最后一集”。绝不在 M10-B 自动播放下一集。
- 只对当前原生 session ID 的 `Error` 显示失败并提供“重试本集”；重新打开失败时不更新选集索引或重试循环。
- 新剧集打开成功才更新上下文；手动停止、单独打开 MP4/HTTPS 或进入原有 M8 本地队列成功时清空 Provider 剧集上下文。
- **独立于 M8 本地视频的自动连播**；不会为 demo/manifest 网络单集默认启用自动切集。
- 不修改 libmpv、Rust 本地历史/断点续播/收藏数据库；跨重启剧集级进度留给 M10-C。
