- 本阶段由 M11-B PR #23 的 CI 全绿、Windows 12/12 验收通过提交 `6446271e17b6dc3d59a0a252bd0d65b84d07ad77` 派生。

- 限定能力：**枚举并选择当前媒体内可用的音轨和内嵌字幕轨、关闭字幕**。不支持自动扫描或加载外部字幕、不支持用户自定义字幕文件、不新增媒体解码器、不修改持久化设置。偏好设置留 M11-C2。
- 原有 `sub-auto=no` 仍保留，避免未经授权自动读取外部字幕文件。

## 技术边界

- `engine.rs` 中的唯一主 libmpv 句柄在 Rust 播放 worker 线程中查询 `track-list/count`、`track-list/N/type`、`id`、`lang`、`title`、`selected`，最多 64 条。
- Rust 将媒体轨道序号、选中状态和清洗后的语言/标题元数据返回 WebView。不返回源 URL/本地绝对路径，过滤控字符、疑似 URL、路径、查询参数和过长元数据。
- `player_tracks(sessionId)`、`player_select_track(sessionId,kind,trackId)` 都经 `spawn_blocking` 与 worker 通信，旧 session 拒绝、未加载或无轨道时安全失败。
- 修改前校验 ID 确实存在于当前 Mpv track-list，音轨只接受真实 ID，字幕允许 null 对应 `sid=no`；使用 mpv 原生 `aid`/`sid` 选择，不重载整个媒体。
- 前端只有取得同 session 的轨道列表后才启用选择器；发起选择后等 Rust 原生返回再更新 UI，不乐观伪造“已切换”。重开/关闭/切集后清空旧列表。
- 继续保障 M11-B 缩略图异步提取与 M11-A 快捷键、原生音视频、M7/M8 进度/队列。

## 准备双音轨 + 内嵌字幕的本地测试 MP4

建议使用项目脚本 `scripts/create-m11c1-fixture.ps1` 创建，不需要私人视频或第三方网站素材。此脚本使用本机合法安装的 FFmpeg，生成约 25 秒的合成视频、两条不同频率的 AAC 音轨（440Hz/660Hz）和一条 MP4 `mov_text` 内嵌字幕。

在 Windows PowerShell 的仓库根目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\create-m11c1-fixture.ps1
```

若 FFmpeg 不在 PATH 中，加 `-FfmpegPath 'C:\path\to\ffmpeg.exe'`；或使用自己有权播放的含多音轨、内嵌字幕 MP4 测试。

请用 FFprobe 或 FFmpeg 媒体信息确认确有 **2 个 audio + 1 个 subtitle** 轨道，再进行功能验收，避免以单音轨素材误判成功。

## Windows 真机验收（12 项）

- [ ] 1. 用双音轨 + 内嵌字幕 MP4，进入播放后「音轨」枚举 2 条（语言/标题可见则显示），「字幕」枚举 1 条和「关闭字幕」。
- [ ] 2. 播放中切换音轨 1/2，能清晰听到 440Hz/660Hz 不同音调，主视频不重新从 0 秒开始，也不打开新窗口。
- [ ] 3. 暂停时切换音轨，恢复播放后选择正确且画面/进度保留。
- [ ] 4. 选择字幕轨后原生视频显示指定时间内字幕；再选「关闭字幕」，画面字幕消失。
- [ ] 5. 反复关闭/开启同一字幕轨，进度、音轨不被改动。
- [ ] 6. 用只有 1 条音轨、无字幕的普通 MP4，字幕选择器禁用，音轨列表准确，不出现错误弹窗或崩溃。
- [ ] 7. Stop、自然 EOF、打开另一部视频后，旧轨道数据消失，不能选择上一会话的轨道 ID。
- [ ] 8. 快速切换不同作品/剧集/本地列表后继续使用选择器，不发生跨 session 误选或旧响应覆盖。
- [ ] 9. HTTPS Demo/自有合法直链 MP4 能枚举实际轨道；单轨或无字幕时正常退化，不出现无效字幕选项。
- [ ] 10. 多次音轨/字幕切换、网络短时缓冲不引发冻结、异常自动连播、音频持续错乱或异常 CPU 占用。
- [ ] 11. 输入焦点、M11-A 快捷键/F11/Esc、M11-B 进度条缩略图和鼠标拖动 Seek 均正常。
- [ ] 12. M7 观看历史/收藏、M8 自动连播、M10-B 手动上下集、M10-C1/C2 首页续播/已看集数以及关闭退出无回归。
